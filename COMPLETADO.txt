🚀 CÓMO USAR
═══════════════════════════════════════════════════════════════════════════

OPCIÓN 1: Con Docker Compose (Recomendado)
────────────────────────────────────────────
1. docker-compose up -d
2. Espera a que se inicien todos los servicios
3. curl -X POST http://localhost:8080/pedidos \
     -H "Content-Type: application/json" \
     -d '{"usuarioId":1,"items":[{"productoId":1,"cantidad":1}]}'

OPCIÓN 2: Desarrollo Local
───────────────────────────
1. Inicia Postgres, RabbitMQ en puertos 5432, 5672
2. Inicia Catalog Service (puerto 8082)
3. Inicia Order Service (puerto 8083)
4. Inicia API Gateway (puerto 8080)
5. Haz requests a http://localhost:8080/pedidos

OPCIÓN 3: Con Maven/IDE
──────────────────────
1. Abre el proyecto en IntelliJ IDEA
2. Configura base de datos PostgreSQL
3. Ejecuta mvn clean install en order-service
4. Run OrderServiceApplication.java
5. El servicio estará en http://localhost:8083

📋 FLUJO DE CREACIÓN DE PEDIDO (Resumido)
═══════════════════════════════════════════════════════════════════════════

1. Cliente envía:
   POST /pedidos
   {"usuarioId": 1, "items": [{"productoId": 5, "cantidad": 2}]}

2. OrderController recibe y delega a OrderService

3. OrderService:
   • Valida usuarioId > 0
   • Valida items no vacíos
   • Para cada item:
     - Consulta CatalogServiceClient
     - HTTP GET a catalog-service:8082/productos/5
     - Valida: existe, activo, stock suficiente
     - Crea OrderItemEntity con snapshot

4. Calcula total y guarda en BD

5. Retorna OrderResponse con toda la información

💾 BASE DE DATOS
═══════════════════════════════════════════════════════════════════════════

Tabla: orders
│ id              │ BIGSERIAL PRIMARY KEY
│ usuario_id      │ BIGINT NOT NULL
│ estado          │ VARCHAR(20) DEFAULT 'PENDING'
│ total           │ DECIMAL(10,2) NOT NULL
│ fecha_creacion  │ TIMESTAMP NOT NULL
│ fecha_actualizacion │ TIMESTAMP NOT NULL

Tabla: order_items
│ id              │ BIGSERIAL PRIMARY KEY
│ orden_id        │ BIGINT NOT NULL (FK → orders)
│ producto_id     │ BIGINT NOT NULL
│ producto_nombre │ VARCHAR(255) NOT NULL
│ cantidad        │ INTEGER NOT NULL
│ precio_unitario │ DECIMAL(10,2) NOT NULL
│ subtotal        │ DECIMAL(10,2) NOT NULL

🔄 ESTADOS DE PEDIDO
═══════════════════════════════════════════════════════════════════════════

PENDING (Inicial)
    ├→ CONFIRMED (Confirmado)
    │   └→ DELIVERED (Final - No cambia)
    │   └→ CANCELLED (Final - No cambia)
    └→ CANCELLED (Final - No cambia)

⚠️ ERRORES POSIBLES Y SOLUCIONES
═══════════════════════════════════════════════════════════════════════════

Error: "Stock insuficiente" (400)
└─ Solución: Aumentar stock en Catalog Service

Error: "Producto no encontrado" (404)
└─ Solución: Crear el producto en Catalog Service

Error: "Pedido no encontrado" (404)
└─ Solución: Verificar que el ID del pedido existe

Error: "No se puede cambiar un pedido entregado" (400)
└─ Solución: Los pedidos DELIVERED o CANCELLED son inmutables

Error: "Connection refused to catalog-service" (500)
└─ Solución: Verificar que Catalog Service está corriendo
