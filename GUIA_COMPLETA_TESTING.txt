PARTE 3: CREAR LOS 5 REQUESTS EN POSTMAN
═══════════════════════════════════════════════════════════════════════════════

📮 REQUEST 1: Crear Producto (requisito previo)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

METHOD:     POST
URL:        {{base_url}}/productos
Header:     Content-Type: application/json

JSON Body:
{
  "titulo": "Cien Años de Soledad",
  "autor": "Gabriel García Márquez",
  "isbn": "978-8439706755",
  "categoria": "Novela",
  "descripcion": "Una novela clásica de la literatura latinoamericana",
  "precio": 50.00,
  "stock": 10
}

✅ ENVÍA (Clic en Send)

Expected Response (200 OK):
{
  "id": 1,
  "titulo": "Cien Años de Soledad",
  "precio": 50.00,
  "stock": 10,
  "activo": true
}

⚠️ COPIA EL ID DEL PRODUCTO (1)


📮 REQUEST 2: Crear Pedido ⭐ (EL MÁS IMPORTANTE)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

METHOD:     POST
URL:        {{base_url}}/pedidos
Header:     Content-Type: application/json

JSON Body:
{
  "usuarioId": 1,
  "items": [
    {
      "productoId": 1,
      "cantidad": 2
    }
  ]
}

✅ ENVÍA (Clic en Send)

Expected Response (200 OK):
{
  "id": 1,
  "usuarioId": 1,
  "estado": "PENDING",
  "total": 100.00,
  "fechaCreacion": "2026-03-12T04:00:09Z",
  "items": [
    {
      "id": 1,
      "productoId": 1,
      "productoNombre": "Cien Años de Soledad",
      "cantidad": 2,
      "precioUnitario": 50.00,
      "subtotal": 100.00
    }
  ]
}

✅ VERIFICA:
   • status: 200 OK ✅
   • total: 100.00 (50 × 2) ✅
   • estado: PENDING ✅

⚠️ COPIA EL ID DEL PEDIDO (1)
